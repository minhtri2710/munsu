# atomic-agent-message-submit

Production symptom: `munsu send` often reports success but text remains in the target agent composer/input without starting a turn. Current Herdr backend `SendKeys` performs two unacknowledged calls: `pane send-text` then `pane send-keys Enter`; success means only that both CLI calls returned zero, not that the agent accepted/submitted the prompt. Herdr 0.7.5 provides atomic `agent prompt <target> <text>` with typed `agent_prompt_stalled`, timeout, and observed-state-change semantics.

Fix inside existing session/message architecture only; no external tooling or unrelated redesign.

Required:
1. Introduce a typed prompt-submission seam distinct from raw terminal SendKeys. Use Herdr `agent prompt` when capability protocol >=17 and target is a recognized live agent; retain raw pane SendKeys only for shell/control commands and capability-declared legacy fallback.
2. A send is successful only after typed submission acknowledgment/state change. Distinguish submitted, queued-while-busy, stalled, unsupported, endpoint-dead, unsafe-composer, and backend-failed.
3. Do not silently fall back after `agent_prompt_stalled`, protocol mismatch, or selected-backend failure. Fallback is allowed only for explicitly unsupported capability and policy-safe target.
4. Wire Captain envelope/outbox, `munsu send`, launch nudges, and report injection through the correct prompt-vs-raw-command seam. `/quit`, launch shell commands, and literal control keys remain raw terminal operations.
5. Preserve durable outbox/envelope until submission is acknowledged; never delete an outbox entry merely because text was written into the composer.
6. Regression/E2E: idle agent submit starts turn; busy queued submit is accepted; composer text remains pending → typed stalled and outbox retained; duplicate retry idempotent; protocol 16 legacy behavior; protocol mismatch fail closed; exact Herdr 0.7.5 isolated named-session test.
7. Preserve one-hop uplink, lifecycle-e2e, global config, and no-force cleanup.

Gate: git diff --check; focused session/captain/cli/composer tests; go build ./...; go vet ./...; go test ./.... Direct-PR; Soldier never merges.
